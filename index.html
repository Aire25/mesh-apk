Cara Kerja Jaringan Offline MeshNet

Aplikasi murni offline tanpa kuota. Semua perangkat terhubung dalam satu area lokal via Wi-Fi Hotspot, Wi-Fi Direct, atau Bluetooth.

Pilih Mode Perangkat Ini
P2P

Langkah Agar Pengguna Lain Ikut Bergabung:

  1. Salah satu HP menyalakan Hotspot Wi-Fi (Tanpa internet/kuota).
  2. HP lain di sekitar menyambungkan Wi-Fi ke Hotspot HP tersebut.
  3. Buka aplikasi MeshNet Pro di semua HP.
  4. Gunakan menu MeshShare atau Ekspor/Impor File Cadangan JSON untuk sinkronisasi data instan antar perangkat.
